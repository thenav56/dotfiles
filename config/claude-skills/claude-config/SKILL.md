# Claude Code config (dotfiles)

`config/claude/` is symlinked to `~/.claude/`.

## settings.json is GENERATED

Do NOT hand-edit `config/claude/settings.json`. It is regenerated by
`commands/claude-settings-gen` and your edits get overwritten.

Edit the source layers instead:

- `config/claude/settings.base.json` -- git-tracked, shared. Normal settings go here.
- `config/claude/settings.local.json` -- private, gitignored (encrypted-store
  symlink, may be absent). Machine-private / secret overrides go here.

## Merge rule (local wins)

- dicts: deep-merged.
- arrays: REPLACED (e.g. a local `hooks` event array fully replaces the base one).
- `{"__append":[...]}`: appends to a base array instead of replacing it.
- scalars: local replaces base.

## Apply changes

- Just launch `claude` -- it is aliased to `commands/claude-custom`, which
  regenerates `settings.json` first.
- Or run `commands/claude-settings-gen` manually.
- Claude Code snapshots settings at session start -- restart to pick up changes.

## Plugins

Do NOT use `/plugin install` or `claude plugin ...` for private plugins (sync
bugs). Plugin merging is NOT wired into this system yet.
